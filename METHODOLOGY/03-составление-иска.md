# Составление искового заявления

## Назначение

Формирование искового заявления, отвечающего требованиям статьи 131 ГПК РФ (для судов общей юрисдикции) или статьи 125 АПК РФ (для арбитражных судов), с учётом правил подсудности и распределения бремени доказывания.

---

## Входные данные

| Данные                                                       | Обязательность            | Примечание                                                   |
| :----------------------------------------------------------- | :------------------------ | :----------------------------------------------------------- |
| Сведения об истце (ФИО/наименование, адрес, контакты, идентификаторы) | Обязательно               | Паспортные данные, ИНН, СНИЛС для граждан; ИНН, ОГРН для организаций |
| Сведения об ответчике (ФИО/наименование, адрес, контакты, идентификаторы) | Обязательно               | По возможности — полные данные                               |
| Фактические обстоятельства нарушения права                   | Обязательно               | Хронология событий, описание действий сторон                 |
| Доказательства, подтверждающие факты                         | Обязательно               | Ссылки на документы, которые будут приложены                 |
| Нормы закона, обосновывающие требование                      | Обязательно               | Статьи материального права (ГК РФ, ЗК РФ, ВК РФ, ЖК РФ, специальные законы) |
| Расчёт взыскиваемой суммы (если есть денежное требование)    | Обязательно при цене иска | С указанием периодов, ставок, сумм                           |
| Сведения о соблюдении досудебного порядка (если требуется)   | По ситуации               | Копия претензии, доказательство направления, ответ           |
| Сведения о предпринятых действиях по примирению              | Опционально               | Медиация, переговоры, предложения о мирном урегулировании    |

---

## Алгоритм составления (6 шагов)

### Шаг 1. Определение подсудности

Перед составлением иска необходимо определить, в какой суд следует обращаться.

#### 1.1. Родовая подсудность (какой суд)

| Категория дела                                               | Суд                         | Основание         |
| :----------------------------------------------------------- | :-------------------------- | :---------------- |
| Дела с ценой иска до 50 000 руб. (кроме споров о земле, наследовании, интеллектуальной собственности) | Мировой судья               | Ст. 23 ГПК РФ     |
| Дела с ценой иска выше 50 000 руб., а также земельные споры (независимо от цены) | Районный (городской) суд    | Ст. 24 ГПК РФ     |
| Дела с участием прокурора, споры о правах на земельные участки, здания, строения | Районный (городской) суд    | Ст. 24, 30 ГПК РФ |
| Споры между юридическими лицами, ИП, а также с их участием (экономические споры) | Арбитражный суд субъекта РФ | Ст. 27 АПК РФ     |

#### 1.2. Территориальная подсудность (куда именно)

| Правило                                             | Применение                                                   | Основание                    |
| :-------------------------------------------------- | :----------------------------------------------------------- | :--------------------------- |
| **Общее правило**                                   | По месту жительства ответчика (для граждан) или по адресу ответчика (для организаций) | Ст. 28 ГПК РФ, ст. 35 АПК РФ |
| **Исключительная подсудность для земельных споров** | По месту нахождения земельного участка                       | Ст. 30 ГПК РФ                |
| **Подсудность по выбору истца**                     | Иски о защите прав потребителей, о возмещении вреда, о восстановлении трудовых прав — по месту жительства истца | Ст. 29 ГПК РФ                |
| **Договорная подсудность**                          | По соглашению сторон (если не нарушает исключительную подсудность) | Ст. 32 ГПК РФ                |

**Алгоритм выбора суда:**

1. Определить, подведомственно ли дело суду общей юрисдикции (ГПК РФ) или арбитражному суду (АПК РФ).
2. Если дело подсудно суду общей юрисдикции — проверить, есть ли исключительная подсудность (ст. 30 ГПК РФ). Для земельных споров — по месту нахождения участка.
3. При отсутствии исключительной подсудности — определить подсудность по общему правилу (по месту жительства/нахождения ответчика).
4. Проверить, возможно ли применение подсудности по выбору истца.

#### 1.3. Формат вывода (для служебного использования)

```markdown
**Определено:**
- Суд: [наименование суда, адрес]
- Основание: [статья закона]
```

### Шаг 2. Формирование шапки искового заявления

В правом верхнем углу указывается:

#### 2.1. Шапка для суда общей юрисдикции (ГПК РФ)

```markdown
В [наименование суда]
Адрес суда: [индекс, город, улица, дом]

Истец: [ФИО полностью]
[Паспорт: серия, номер, кем и когда выдан]
[Адрес регистрации: индекс, город, улица, дом, кв.]
[Адрес фактического проживания (если отличается): ...]
[Телефон: номер]
[Эл. почта: адрес]
[ИНН: номер] (при наличии)
[СНИЛС: номер] (при наличии)

Ответчик: [ФИО или наименование полностью]
[Для гражданина: адрес регистрации]
[Для организации: ИНН, ОГРН, адрес]
[Телефон: номер (если известен)]
[Эл. почта: адрес (если известен)]

Цена иска: [сумма цифрами и прописью] (если применимо)
Государственная пошлина: [уплачена / подлежит уплате]
```

#### 2.2. Шапка для арбитражного суда (АПК РФ)

```markdown
В Арбитражный суд [наименование субъекта РФ]
Адрес суда: [индекс, город, улица, дом]

Истец: [полное наименование организации]
[ОГРН: номер]
[ИНН: номер]
[КПП: номер]
[Адрес: индекс, город, улица, дом]
[Телефон: номер]
[Эл. почта: адрес]

Ответчик: [полное наименование организации]
[ОГРН: номер]
[ИНН: номер]
[Адрес: индекс, город, улица, дом]

Цена иска: [сумма цифрами и прописью] (если применимо)
Государственная пошлина: [уплачена / подлежит уплате]
```

#### 2.3. Важное примечание об идентификаторах

В соответствии с пунктами 2 и 3 части 2 статьи 131 ГПК РФ (в редакции от 18.03.2023), в исковом заявлении должны быть указаны **один из идентификаторов** гражданина-истца и гражданина-ответчика:

- страховой номер индивидуального лицевого счета (СНИЛС);
- идентификационный номер налогоплательщика (ИНН);
- серия и номер документа, удостоверяющего личность;
- основной государственный регистрационный номер индивидуального предпринимателя (ОГРНИП);
- серия и номер водительского удостоверения.

Если информация об идентификаторе ответчика неизвестна, об этом указывается в иске. Суд вправе запросить недостающие сведения.

### Шаг 3. Формирование вводной части

1–2 предложения о том, какое правоотношение и какое нарушение лежат в основе иска.

**Формула вводной части:**

```markdown
ИСКОВОЕ ЗАЯВЛЕНИЕ
о [кратко указать суть требования]
```

**Примеры:**

- *«о признании права собственности на земельный участок»*
- *«об истребовании имущества из чужого незаконного владения»*
- *«о взыскании задолженности по договору управления»*
- *«о признании недействительным решения общего собрания»*

---

### Шаг 4. Формирование описательной части (обстоятельства)

Изложить факты, обосновывающие требования, в хронологическом порядке.

#### 4.1. Принципы изложения

| Принцип                                        | Что делать                              | Чего избегать                         |
| :--------------------------------------------- | :-------------------------------------- | :------------------------------------ |
| **Одно предложение — одна мысль**              | Короткие предложения (10–15 слов)       | Длинных, запутанных конструкций       |
| **Каждый факт — со ссылкой на доказательство** | «… что подтверждается договором №… от…» | Голословных утверждений               |
| **Только юридически значимые обстоятельства**  | Даты, цифры, имена, события             | Лишних деталей, не относящихся к делу |
| **Хронологический порядок**                    | Сначала то, что было раньше             | Хаотичного изложения                  |

#### 4.2. Структура описательной части для различных типов исков

| Тип иска                                             | Базовая структура                                            |
| :--------------------------------------------------- | :----------------------------------------------------------- |
| **О признании права собственности**                  | Основание возникновения права (договор, приватизация, наследство, приобретательная давность) → регистрация права (если была) → факт оспаривания права ответчиком (или угроза оспаривания) → нарушение прав истца |
| **Виндикационный (об истребовании имущества)**       | Право собственности истца на имущество → нахождение этого имущества у ответчика → отсутствие законных оснований владения у ответчика → отказ ответчика вернуть имущество |
| **Негаторный (об устранении препятствий)**           | Право собственности истца на участок/объект → факт создания ответчиком препятствий в пользовании (указать каких) → длящийся характер нарушения (на момент подачи иска) |
| **О взыскании задолженности (УК, СНТ, по договору)** | Основание обязательства (договор, членство, решение собрания) → неисполнение ответчиком обязательства → расчёт задолженности (с периодами, ставками) → направление претензии (если требуется) → отсутствие удовлетворения |
| **О признании решения собрания недействительным**    | Факт проведения собрания (дата, форма) → истец является членом/участником → нарушение процедуры (отсутствие кворума, ненадлежащее уведомление, превышение полномочий) → нарушение прав истца данным решением |
| **Об установлении границ земельного участка**        | Право собственности истца на участок → наличие кадастровой ошибки или спора со смежником → результаты кадастровых работ/экспертизы → предложение варианта установления границ |
| **О сносе самовольной постройки**                    | Право собственности истца на земельный участок → возведение ответчиком строения → признаки самовольной постройки (отсутствие разрешения, нарушение целевого назначения, нарушение норм) → угроза правам истца |

#### 4.3. Пример описательной части (для земельного спора)

```markdown
**1. Обстоятельства, на которых основан иск**

1.1. Истец является собственником земельного участка с кадастровым номером 50:08:0000000:15 площадью 4 043 489 кв. м, категория земель — «земли сельскохозяйственного назначения», что подтверждается выпиской из ЕГРН от 15.01.2024 № 1234 (приложение № 1).

1.2. Указанный земельный участок приобретён истцом на основании договора купли-продажи № 75 от 09.09.2004, заключённого с Министерством имущественных отношений Московской области (приложение № 2). Право собственности зарегистрировано в установленном порядке, что подтверждается свидетельством о государственной регистрации права от 12.10.2004 серия 50 АЖ № 057882 (приложение № 3).

1.3. В границах земельного участка истца расположены пруды, созданные искусственным путём в 1971 году для целей прудовой аквакультуры, что подтверждается технической документацией на гидротехнические сооружения (приложение № 4) и актами ввода в эксплуатацию (приложение № 5).

1.4. [Далее — описание нарушения права]
```

### Шаг 5. Формирование правового обоснования

#### 5.1. Структура правового обоснования

Построить логическую цепочку.

**Формула:**

```markdown
В соответствии со статьёй [номер закона] [суть нормы].

В данном случае установлено, что [конкретное обстоятельство], что подтверждается [доказательство].

Следовательно, [вывод о нарушении права или о праве истца].
```

#### 5.2. Пример правового обоснования

```markdown
**2. Правовое обоснование требований**

2.1. В соответствии с частью 2 статьи 8 Водного кодекса РФ пруд, расположенный в границах земельного участка, принадлежащего на праве собственности юридическому лицу, находится в собственности этого юридического лица.

В данном случае пруды расположены в границах земельного участка с кадастровым номером 50:08:0000000:15, принадлежащего истцу на праве собственности, что подтверждается выпиской из ЕГРН (приложение № 1) и договором купли-продажи (приложение № 2).

Следовательно, пруды, расположенные в границах участка истца, являются его собственностью.

2.2. [Следующий аргумент]
```

#### 5.3. Ссылки на судебную практику (при наличии)

Если есть судебные акты вышестоящих судов по аналогичным делам, указать их.

```markdown
Аналогичная правовая позиция изложена в определении Верховного Суда РФ от 15.03.2023 № 123-КГ23-45, согласно которой [суть позиции].
```

### Шаг 6. Формирование просительной части

#### 6.1. Правила формулирования требований

| Правило                           | Плохо                                     | Хорошо                                                       |
| :-------------------------------- | :---------------------------------------- | :----------------------------------------------------------- |
| **Конкретность**                  | «Обязать ответчика устранить нарушения»   | «Обязать ответчика демонтировать ограждение длиной 50 метров вдоль восточной границы земельного участка с кадастровым номером...» |
| **Исполнимость**                  | «Вернуть всё как было»                    | «Обязать ответчика освободить земельный участок площадью 500 кв. м и передать его истцу по акту приёма-передачи» |
| **Соответствие закону**           | «Признать ответчика злостным нарушителем» | «Признать недействительным договор аренды № 123 от 01.01.2020» |
| **Логическая последовательность** | Несколько требований вразнобой            | Сначала о признании права, потом об истребовании имущества   |

#### 6.2. Стандартные формулировки требований

| Ситуация                                      | Формулировка                                                 |
| :-------------------------------------------- | :----------------------------------------------------------- |
| Иск о признании права собственности           | «Признать право собственности истца на [объект] с кадастровым номером ...» |
| Виндикационный иск                            | «Истребовать из незаконного владения ответчика [объект] и передать его истцу» |
| Негаторный иск                                | «Обязать ответчика устранить препятствия в пользовании [объектом], а именно: [конкретное действие]» |
| О взыскании задолженности                     | «Взыскать с ответчика в пользу истца задолженность в размере _____ рублей, в том числе основной долг _____ рублей, пени _____ рублей» |
| О признании решения собрания недействительным | «Признать недействительным решение общего собрания [наименование] от [дата], оформленное протоколом № ...» |
| Об установлении границ                        | «Установить границы земельного участка с кадастровым номером ... в соответствии с координатами, указанными в межевом плане от [дата], выполненном кадастровым инженером [ФИО]» |
| О сносе самовольной постройки                 | «Обязать ответчика за свой счет снести (демонтировать) [объект], расположенный по адресу ...» |

#### 6.3. Структура просительной части

```markdown
**3. Требования**

На основании изложенного, руководствуясь статьями [перечислить нормы процессуального права: 131-132 ГПК РФ или 125-126 АПК РФ],

**ПРОШУ СУД:**

1. [первое требование]
2. [второе требование]
3. ...
```

### Шаг 7. Формирование перечня приложений

Перечислить документы, прилагаемые к иску в соответствии со статьёй 132 ГПК РФ или статьёй 126 АПК РФ.

#### 7.1. Обязательные приложения

| №    | Документ                                                     | Примечание                                           |
| :--- | :----------------------------------------------------------- | :--------------------------------------------------- |
| 1    | Копия искового заявления для ответчика (и третьих лиц)       | По числу участников процесса                         |
| 2    | Документ об уплате государственной пошлины                   | В подлиннике                                         |
| 3    | Доверенность (если иск подписывает представитель)            | Оригинал или нотариально заверенная копия            |
| 4    | Документы, подтверждающие обстоятельства, на которых основан иск | Копии (по числу участников)                          |
| 5    | Расчёт взыскиваемой суммы (если есть)                        | Подписанный истцом или представителем                |
| 6    | Документы, подтверждающие соблюдение досудебного порядка (если требуется) | Копии (претензия, доказательство направления, ответ) |
| 7    | Уведомление о вручении или иные документы, подтверждающие направление копий иска другим лицам | Особенно важно для АПК                               |

#### 7.2. Формат перечня

```markdown
**Приложение:**

1. Копия искового заявления для ответчика — 1 экз. на [число] л.
2. Документ об уплате государственной пошлины — 1 экз. на 1 л.
3. Копия выписки из ЕГРН от [дата] № ... — 1 экз. на [число] л.
4. Копия договора купли-продажи № 75 от 09.09.2004 — 1 экз. на [число] л.
5. Копия технической документации на гидротехнические сооружения — 1 экз. на [число] л.
6. ...
```

## Контрольный чек-лист перед подачей

Перед подачей искового заявления проверить:

| №    | Проверка                                                     | Статус |
| :--- | :----------------------------------------------------------- | :----- |
| 1    | Наименование суда указано правильно                          | ☐      |
| 2    | Истец указан с полными реквизитами (ФИО/наименование, адрес, паспорт/ИНН, телефон) | ☐      |
| 3    | Ответчик указан с полными реквизитами (ФИО/наименование, адрес, по возможности — ИНН, ОГРН) | ☐      |
| 4    | Цена иска рассчитана верно (если есть)                       | ☐      |

## Типовые ошибки при составлении иска

| Ошибка                                                     | Последствие                                                | Как избежать                                                 |
| :--------------------------------------------------------- | :--------------------------------------------------------- | :----------------------------------------------------------- |
| Не указан идентификатор ответчика (СНИЛС, ИНН)             | Суд может запросить информацию, затягивается принятие иска | Указать известные данные, если неизвестны — прямо об этом указать в иске |
| Нет доказательств направления копии иска ответчику (в АПК) | Иск будет возвращён                                        | Приложить уведомление о вручении или почтовую квитанцию с описью |
| Просительная часть неконкретна                             | Суд может отказать в иске или оставить без движения        | Формулировать требования как приказы суду: «обязать», «взыскать», «признать» |
| Не приложен расчёт взыскиваемой суммы                      | Иск будет оставлен без движения                            | Сделать расчёт даже для очевидных сумм                       |
| Пропущен срок исковой давности                             | Отказ в иске (при заявлении ответчика)                     | Проверить срок до подачи, при пропуске — обосновать уважительность причин |
| Не соблюдён досудебный порядок                             | Возврат иска или оставление без рассмотрения               | Направить претензию, дождаться ответа или истечения срока    |
| Иск подан в суд не по месту нахождения земельного участка  | Передача дела в другой суд                                 | Для земельных споров всегда подавать по месту нахождения объекта (ст. 30 ГПК РФ) |

## Ограничения метода

Настоящий алгоритм не заменяет:

- Проверку актуальности нормативных правовых актов на момент подачи иска
- Анализ судебной практики по аналогичным делам в конкретном регионе
- Консультацию с квалифицированным юристом по сложным или нестандартным делам

Сформированное исковое заявление является проектом, требующим финальной проверки и адаптации под конкретные обстоятельства дела.
