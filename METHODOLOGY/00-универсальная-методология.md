# Универсальная методология формирования и реализации правовой позиции

## (Инструкция для систем искусственного интеллекта)

**Назначение документа:** настоящий документ содержит формализованную методологию анализа любого судебного спора и синтеза правовой позиции стороны. Документ предназначен для использования системой искусственного интеллекта в качестве промпта при обработке конкретных материалов дела. Результатом применения методологии является структурированная правовая позиция, пригодная для использования в судебном процессе, а также проекты необходимых процессуальных документов.

---

## Исходные данные для запуска универсальной правовой позиции

Для того чтобы система искусственного интеллекта (ИИ) могла применить методологию из раздела «Теория» и сформировать правовую позицию, необходимо предоставить следующие исходные данные. Данные разделены на категории по степени обязательности.

#### 7. Ограничения

Настоящий список исходных данных не гарантирует:

- Полноту всех необходимых данных для конкретного типа спора (возможны дополнительные запросы)
- Успешный исход судебного разбирательства (результат зависит от качества доказательств, процессуального поведения сторон и судейского усмотрения)
- Замену квалифицированной юридической консультации по сложным или нестандартным делам

При недостаточности исходных данных ИИ запросит недостающую информацию в диалоговом режиме.

## Глава 1. Общие положения

### 1.1. Инвариантные принципы (действуют для любого спора)

| №    | Принцип                               | Содержание                                                   |
| :--- | :------------------------------------ | :----------------------------------------------------------- |
| 1    | **Структура правовой позиции**        | Любая правовая позиция строится по формуле: **Норма закона → Факт → Вывод**. Отсутствие любого элемента превращает утверждение в декларацию. |
| 2    | **Распределение бремени доказывания** | Истец доказывает основания иска. Ответчик доказывает свои возражения. Никто не обязан доказывать то, на что не ссылается. |
| 3    | **Приоритет специальной нормы**       | При конкуренции общей и специальной норм применяется специальная норма (*lex specialis derogat legi generali*). |
| 4    | **Четыре элемента спора**             | Любой спор разлагается на: фактические обстоятельства, правовые нормы, доказательства, процессуальные действия. |
| 5    | **Критерии оценки доказательств**     | Относимость, допустимость, достоверность, достаточность. Для опровержения доказательства достаточно «пробить» один критерий. |

### 1.2. Иерархия нормативных актов

| Уровень | Вид акта                                             | Обязательность для суда               |
| :------ | :--------------------------------------------------- | :------------------------------------ |
| 1       | Конституция РФ                                       | Высшая                                |
| 2       | Федеральные конституционные законы                   | Прямая                                |
| 3       | Кодексы (ЗК РФ, ВК РФ, ГК РФ, ЖК РФ, ГПК РФ, АПК РФ) | Прямая                                |
| 4       | Федеральные законы                                   | Прямая                                |
| 5       | Подзаконные акты                                     | Косвенная                             |
| 6       | Ведомственные письма и разъяснения                   | Отсутствует (суд не обязан применять) |

Акты РСФСР и СССР, а также ведомственные письма не подлежат применению как недействующие или не имеющие обязательной силы.

### 1.3. Процессуальные сроки (основные)

| Действие                           | Срок     | Исчисление                                                   | Последствие пропуска                     |
| :--------------------------------- | :------- | :----------------------------------------------------------- | :--------------------------------------- |
| Апелляционная жалоба (ГПК, АПК)    | 1 месяц  | Со дня принятия решения в окончательной форме                | Возврат жалобы (возможно восстановление) |
| Кассационная жалоба (ГПК)          | 3 месяца | Со дня вступления решения в законную силу                    | Возврат жалобы                           |
| Исковая давность (общий срок)      | 3 года   | Со дня, когда лицо узнало или должно было узнать о нарушении | Отказ в иске                             |
| Предъявление исполнительного листа | 3 года   | Со дня вступления решения в законную силу                    | Отказ в возбуждении производства         |

## Глава 2. Анализ судебного иска

### 2.1. Назначение

Выявление слабых мест в позиции истца, определение процессуальных нарушений и формирование основы для возражений.

### 2.2. Алгоритм анализа (10 шагов)

#### Шаг 1. Извлечение требований истца (просительная часть)

Найти в иске просительную часть (обычно начинается со слов «Прошу суд:», «На основании изложенного, прошу:»).

**Формат вывода:**

### Требования истца
1. [требование 1]
2. [требование 2]
...

#### Шаг 2. Извлечение правовых оснований (норм)

Найти в иске все упоминания статей законов, кодексов, иных нормативных актов.

**Формат вывода:**

### Правовые основания истца
| № | Норма (статья, часть, пункт) | К какому требованию относится |
| :--- | :--- | :--- |
| 1 | ... | требование № ... |
| 2 | ... | требование № ... |

#### Шаг 3. Извлечение фактических утверждений

Выписать все утверждения истца о событиях, действиях, состояниях. Отделить факты от мнений и предположений.

| Тип утверждения   | Определение                                              | Признак                                                      |
| :---------------- | :------------------------------------------------------- | :----------------------------------------------------------- |
| **Факт**          | Утверждение о конкретном событии, подлежащее доказыванию | Указывает на: дату, место, действие, состояние, наличие/отсутствие чего-либо |
| **Мнение**        | Субъективная оценка, не подлежащая доказыванию           | Содержит слова: «по мнению», «очевидно», «полагаю», «вероятно» |
| **Предположение** | Утверждение о вероятности, без указания источника        | Содержит слова: «возможно», «предположительно», «может быть» |

#### Шаг 4. Извлечение доказательств истца

Выписать все документы и сведения, на которые ссылается истец в подтверждение своих утверждений.

**Формат вывода:**

### Доказательства истца
| № | Доказательство | Какой факт подтверждает |
| :--- | :--- | :--- |
| 1 | ... | ... |

#### Шаг 5. Проверка правовых оснований (для каждой нормы)

Для каждой нормы, указанной истцом, выполнить проверку:

**Вопрос 1: Действует ли норма?**

| Результат           | Действие                                   |
| :------------------ | :----------------------------------------- |
| Норма действует     | Перейти к вопросу 2                        |
| Норма утратила силу | Зафиксировать как основание для возражения |
| Норма изменена      | Использовать действующую редакцию          |

**Вопрос 2: Относится ли норма к ситуации?**

| Результат                             | Действие                                   |
| :------------------------------------ | :----------------------------------------- |
| Норма регулирует тот же вид отношений | Перейти к вопросу 3                        |
| Норма регулирует иные отношения       | Зафиксировать как основание для возражения |

**Вопрос 3: Соблюдены ли условия применения нормы?**

У каждой нормы есть условия применения (слова «если», «при условии», «в случае»). Проверить, соблюдены ли эти условия в данном деле.

| Результат            | Действие                                   |
| :------------------- | :----------------------------------------- |
| Условия соблюдены    | Норма применима                            |
| Условия не соблюдены | Зафиксировать как основание для возражения |

#### Шаг 6. Оценка доказательств истца (четыре критерия)

| Критерий          | Вопрос                                                       | При нарушении               |
| :---------------- | :----------------------------------------------------------- | :-------------------------- |
| **Относимость**   | Подтверждает ли доказательство факты, входящие в предмет доказывания? | Доказательство неотносимо   |
| **Допустимость**  | Получено ли доказательство законным способом, оформлено ли надлежащим образом? | Доказательство недопустимо  |
| **Достоверность** | Нет ли противоречий с иными доказательствами или официальными данными? | Доказательство недостоверно |
| **Достаточность** | Достаточно ли доказательства (или их совокупности) для однозначного вывода? | Доказательств недостаточно  |

**Стандартные аргументы для атаки на доказательства:**

| Тип доказательства               | Основания для атаки                                          |
| :------------------------------- | :----------------------------------------------------------- |
| Заключение кадастрового инженера | Выход за пределы компетенции (правовые выводы), отсутствие извещения другой стороны, противоречие официальным данным |
| Фотографии с интернет-карт       | Ненадлежащий источник, недопустимое доказательство           |
| Показания заинтересованных лиц   | Отсутствие независимости, нужда в подтверждении письменными доказательствами |
| Односторонние акты               | Составлены без участия другой стороны, не направлены, не подтверждают факт оказания услуг |
| Протокол собрания                | Отсутствие доказательств кворума, надлежащего уведомления    |

#### Шаг 7. Выявление процессуальных нарушений

| №    | Нарушение                        | Что проверять                                              | Норма                        |
| :--- | :------------------------------- | :--------------------------------------------------------- | :--------------------------- |
| 1    | Неподведомственность             | Дело не подсудно данному суду                              | Ст. 22–30 ГПК РФ             |
| 2    | Пропуск срока исковой давности   | Требование заявлено по истечении 3 лет с момента нарушения | Ст. 196, 200 ГК РФ           |
| 3    | Отсутствие полномочий у истца    | Истец не вправе подавать такой иск (особенно прокурор)     | Ст. 45 ГПК РФ, ст. 52 АПК РФ |
| 4    | Несоблюдение досудебного порядка | Требуется претензия, но она не направлялась                | Ст. 132 ГПК РФ               |

**Специфика прокурорских исков (ст. 45 ГПК РФ, ст. 52 АПК РФ):**

Прокурор должен обосновать:

| Что проверить                                                | Отсутствие обоснования → основание для возражения |
| :----------------------------------------------------------- | :------------------------------------------------ |
| В чьих интересах подан иск (конкретное лицо, неопределённый круг лиц, РФ, субъект РФ, муниципалитет) | Иск подан в интересах, которые не определены      |
| Если в интересах гражданина — почему гражданин не может обратиться самостоятельно | Гражданин может обратиться самостоятельно         |
| Если в интересах РФ — какой конкретный интерес РФ нарушен    | Интерес РФ не показан чётко и ясно                |

| Высокий   | Пропущен срок исковой давности                               |

## Глава 4. Формулирование правовой позиции

### 4.1. Назначение

Создание системы взаимосвязанных утверждений (триад «Факт — Доказательство — Норма»), из которых с неизбежностью следует юридически значимый вывод.

### 4.2. Алгоритм формирования (5 шагов)

#### Шаг 1. Определение целевого вывода

Сформулировать одним предложением тот юридический результат, которого сторона хочет добиться.

**Примеры целевых выводов для ответчика:**

- «Иск не подлежит удовлетворению»
- «В удовлетворении исковых требований отказать полностью»
- «Встречный иск удовлетворить, признав право собственности на земельный участок»

**Примеры целевых выводов для истца:**

- «Исковые требования подлежат удовлетворению в полном объёме»
- «Признать право собственности истца на земельный участок»
- «Взыскать с ответчика сумму неосновательного обогащения»

#### Шаг 2. Декомпозиция целевого вывода на утверждения

Разбить целевой вывод на 3–7 ключевых утверждений, каждое из которых является самостоятельным аргументом.

**Пример для ответчика по иску о изъятии прудов:**

| №    | Утверждение                                                  |
| :--- | :----------------------------------------------------------- |
| 1    | Пруды являются частной собственностью ответчика              |
| 2    | Гидравлическая связь с рекой не прекращает право собственности |
| 3    | Статья 85 ЗК РФ не подлежит применению (участок — земли сельхозназначения) |
| 4    | Приватизация 2004 года была законной                         |
| 5    | Ссылки истца на ст. 27 и ст. 102 ЗК РФ не создают оснований для изъятия |

#### Шаг 3. Построение триады для каждого утверждения

**Схема триады:**

| Элемент            | Что указать                                                  | Пример                                                      |
| :----------------- | :----------------------------------------------------------- | :---------------------------------------------------------- |
| **Норма закона**   | Конкретная статья, часть, пункт с указанием акта             | «Часть 2 статьи 8 Водного кодекса РФ»                       |
| **Факт**           | Юридически значимое обстоятельство, подтверждённое доказательством | «Пруды расположены в границах земельного участка ответчика» |
| **Доказательство** | Ссылка на документ, подтверждающий факт                      | «Выписка из ЕГРН на земельный участок»                      |
| **Вывод**          | Логическое следствие                                         | «Следовательно, пруды являются собственностью ответчика»    |

**Формат записи триады:**

### Утверждение [номер]. [Название]

**Норма закона:** [статья, часть, пункт]

**Факт:** [обстоятельство, подтверждённое доказательством]

**Доказательство:** [наименование документа, реквизиты]

**Вывод:** [логическое следствие]

#### Шаг 4. Выстраивание иерархии триад

| Тип триады          | Назначение                                                   | Порядок следования |
| :------------------ | :----------------------------------------------------------- | :----------------- |
| **Базовые**         | Устанавливают фундаментальные обстоятельства (право собственности, легитимность субъекта) | Первыми            |
| **Основные**        | Непосредственно опровергают доводы истца                     | Следом за базовыми |
| **Вспомогательные** | Усиливают основные, блокируют альтернативные аргументы       | Последними         |

#### Шаг 5. Проверка системных связей

Проверить, что триады:

- [ ] Не противоречат друг другу
- [ ] Выстроены в логически последовательную цепочку
- [ ] Совокупность триад ведёт к целевому выводу
- [ ] Каждый факт подтверждён доказательством
- [ ] Каждая норма применима к ситуации

## Глава 5. Составление искового заявления

### 5.1. Назначение

Формирование искового заявления, отвечающего требованиям ст. 131–132 ГПК РФ или ст. 125–126 АПК РФ.

### 5.2. Алгоритм составления (6 шагов)

#### Шаг 1. Формирование шапки

В [наименование суда]
Адрес суда: [индекс, город, улица, дом]

Истец: [ФИО или наименование]
[Паспортные данные / ИНН, ОГРН]
Адрес: [индекс, город, улица, дом]
Телефон: [номер]
Эл. почта: [при наличии]

Ответчик: [ФИО или наименование]
Адрес: [индекс, город, улица, дом]

Цена иска: [сумма, если имущественное требование]
Госпошлина: [если уплачена]

#### Шаг 2. Формирование вводной части

Краткое указание на правоотношение, из которого возник спор, и суть нарушения.

**Пример:** «Между истцом и ответчиком заключён договор купли-продажи земельного участка № 75 от 09.09.2004. Ответчик свои обязательства по договору не исполнил».

#### Шаг 3. Формирование описательной части (обстоятельства)

Изложить факты в хронологическом порядке.

**Принципы изложения:**

- Каждый абзац — одна мысль (3–5 предложений)
- Каждый факт — со ссылкой на доказательство («… что подтверждается договором №…»)
- Только юридически значимые обстоятельства

**Структура для типовых исков:**

| Тип иска                                      | Базовая структура                                            |
| :-------------------------------------------- | :----------------------------------------------------------- |
| О признании права                             | Возникновение права → регистрация (если есть) → факт оспаривания → нарушение |
| Виндикационный                                | Право истца → нахождение имущества у ответчика → отсутствие законных оснований |
| Негаторный                                    | Право истца → факт создания препятствий → длящийся характер нарушения |
| О взыскании                                   | Основание обязательства → неисполнение → расчёт задолженности |
| О признании решения собрания недействительным | Факт проведения собрания → нарушение процедуры (отсутствие кворума, ненадлежащее уведомление) → нарушение прав истца |

#### Шаг 4. Формирование правового обоснования

Построить логическую цепочку:

**Формула:**

> «В соответствии со статьёй [номер] [закона] [суть нормы]. В данном случае установлено [конкретное обстоятельство], что подтверждается [доказательство]. Следовательно, [вывод о нарушении права]».

#### Шаг 5. Формирование просительной части

**Требования к формулировкам:**

| Плохо                                   | Хорошо                                                       |
| :-------------------------------------- | :----------------------------------------------------------- |
| «Обязать ответчика устранить нарушения» | «Обязать ответчика демонтировать ограждение длиной 50 метров вдоль восточной границы участка» |
| «Признать договор ничтожным»            | «Признать недействительным договор №... от [дата] и применить последствия недействительности ничтожной сделки» |
| «Взыскать задолженность»                | «Взыскать задолженность в размере _____ рублей: основной долг _____ рублей, пени _____ рублей» |

**Стандартные формулировки:**

| Ситуация                             | Формулировка                                                 |
| :----------------------------------- | :----------------------------------------------------------- |
| Иск о признании права                | «Признать право собственности истца на земельный участок с кадастровым номером ...» |
| Виндикационный иск                   | «Истребовать из незаконного владения ответчика земельный участок с кадастровым номером ... и передать его истцу» |
| Негаторный иск                       | «Обязать ответчика устранить препятствия в пользовании земельным участком, а именно: [конкретные действия]» |
| О признании решения недействительным | «Признать недействительным решение общего собрания [наименование] от [дата], оформленное протоколом № ...» |

#### Шаг 6. Формирование приложений

Обязательный перечень (ст. 132 ГПК РФ):

1. Копия иска для ответчика (и третьих лиц)
2. Документ об уплате госпошлины
3. Доверенность (если иск подаёт представитель)
4. Документы, подтверждающие обстоятельства, на которых основан иск
5. Расчёт взыскиваемой суммы (если есть)
6. Документы, подтверждающие досудебный порядок (если требуется)

### 5.3. Контрольный чек-лист

Перед завершением составления проверить:

- [ ] Наименование суда указано правильно
- [ ] Истец и ответчик указаны с полными реквизитами
- [ ] Цена иска рассчитана верно (если есть)
- [ ] Каждый факт в описательной части имеет ссылку на доказательство
- [ ] Каждое требование в просительной части конкретно и исполнимо
- [ ] Указаны нормы закона в обоснование
- [ ] Приложены все необходимые документы
- [ ] Есть доказательство направления копии иска ответчику

## Глава 8. Общий контрольный чек-лист

Перед формированием итоговой правовой позиции проверить:

### 8.1. Анализ спора
- [ ] Определена категория земель (если применимо)
- [ ] Определён вид объекта спора
- [ ] Определён субъектный состав
- [ ] Определён вид иска
- [ ] Определено основание возникновения права

### 8.2. Анализ позиции истца
- [ ] Выписаны все требования истца
- [ ] Выписаны все нормы, на которые ссылается истец
- [ ] Для каждой нормы проверена: действует ли, относится ли к ситуации, соблюдены ли условия
- [ ] Выписаны все фактические утверждения истца
- [ ] Для каждого утверждения определён тип (факт, мнение, предположение)
- [ ] Оценены доказательства истца по четырём критериям
- [ ] Выявлены процессуальные нарушения

### 8.3. Формирование правовой позиции
- [ ] Сформулирован целевой вывод
- [ ] Сформулированы 3–7 ключевых утверждений
- [ ] Для каждого утверждения построена триада «Норма → Факт → Доказательство → Вывод»
- [ ] Триады не противоречат друг другу
- [ ] Триады выстроены в логической последовательности
- [ ] Совокупность триад ведёт к целевому выводу

### 8.4. Доказательственная база
- [ ] Составлен список имеющихся доказательств
- [ ] Составлен список отсутствующих доказательств
- [ ] Для каждого отсутствующего доказательства определён способ получения
- [ ] Все доказательства оформлены надлежащим образом
- [ ] Подготовлены копии для другой стороны
- [ ] Подготовлены доказательства направления копий

### 8.5. Процессуальная часть
- [ ] Проверен срок исковой давности
- [ ] Проверена подсудность
- [ ] Проверены полномочия лица, подписавшего иск
- [ ] Проверено соблюдение досудебного порядка
