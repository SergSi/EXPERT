# Формулирование правовой позиции

## Назначение

Создание системы взаимосвязанных утверждений (триад «Факт — Доказательство — Норма»), из которых с неизбежностью следует юридически значимый вывод. Правовая позиция является основой для отзыва на иск, встречного иска, апелляционной жалобы и устных выступлений в суде.

---

## Входные данные

| Данные                                                      | Источник                          | Обязательность                   |
| :---------------------------------------------------------- | :-------------------------------- | :------------------------------- |
| Результат анализа иска (из 01-анализ-иска.md)               | Сформирован ранее                 | Обязательно (если иск уже подан) |
| Результат оценки перспектив (из 02-анализ-перспектив.md)    | Сформирован ранее                 | Желательно                       |
| Фактические обстоятельства дела                             | Пользователь                      | Обязательно                      |
| Собранные доказательства (документы, заключения, показания) | Пользователь                      | Обязательно                      |
| Целевой правовой результат (чего хотим добиться)            | Пользователь                      | Обязательно                      |
| Судебная практика по аналогичным делам (при наличии)        | Пользователь / справочные системы | Желательно                       |

## Алгоритм формирования (5 шагов)

### Шаг 1. Декомпозиция целевого вывода

Разбить итоговый вывод на составные части — от 3 до 7 ключевых утверждений. Каждое утверждение должно быть самостоятельным юридически значимым суждением, которое может быть доказано или опровергнуто независимо от других.

#### 1.1. Типовые целевые выводы и их декомпозиция

| Целевой вывод                             | Возможная декомпозиция (ключевые утверждения)                |
| :---------------------------------------- | :----------------------------------------------------------- |
| **Иск не подлежит удовлетворению**        | 1. Истец применил нормы, не подлежащие применению<br>2. К спорным правоотношениям подлежат применению специальные нормы<br>3. Право собственности ответчика возникло законно<br>4. Истец не доказал обстоятельства, на которые ссылается<br>5. Истцом пропущен срок исковой давности |
| **Право собственности подлежит защите**   | 1. Право собственности возникло на законных основаниях<br>2. Право собственности зарегистрировано в установленном порядке<br>3. Право собственности никем не оспорено и не прекращено<br>4. Нарушение права подтверждено доказательствами<br>5. Нарушение носит длящийся характер |
| **Встречный иск подлежит удовлетворению** | 1. Между сторонами существует правоотношение, предусматривающее обязанность истца по первоначальному иску<br>2. Истец по первоначальному иску не исполнил эту обязанность<br>3. Размер требований подтверждён расчётом<br>4. Досудебный порядок соблюдён (если требуется) |
| **Решение собрания недействительно**      | 1. Собрание проведено с нарушением процедуры уведомления<br>2. При принятии решения отсутствовал кворум<br>3. Решение принято по вопросу, не относящемуся к компетенции собрания<br>4. Решением нарушены права истца |

#### 1.2. Формат вывода

```markdown
**Целевой вывод:** [одно предложение]

**Ключевые утверждения:**
1. [утверждение 1]
2. [утверждение 2]
3. [утверждение 3]
...
```

### Шаг 2. Построение триад (Факт — Доказательство — Норма)

Для каждого ключевого утверждения (из Шага 1) построить триаду по единой схеме.

#### 2.1. Структура триады

| Элемент            | Что указать                                                  | Требования к формулировке                                    |
| :----------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **Норма закона**   | Конкретная статья, часть, пункт нормативного правового акта с указанием источника | Действующая норма; специальная норма имеет приоритет над общей |
| **Факт**           | Юридически значимое обстоятельство, подтверждённое доказательством | Конкретное, проверяемое, относящееся к делу                  |
| **Доказательство** | Ссылка на документ или иной источник сведений о факте        | Допустимое, относимое, достоверное                           |
| **Вывод**          | Логическое следствие из подведения факта под норму           | Формулируется как «следовательно...»                         |

#### 2.2. Правила построения триад

**Правило 1. Норма должна быть действующей и применимой.**

Проверить по нормативной базе:
- Норма не утратила силу
- Норма относится к данной категории правоотношений
- Условия применения нормы соблюдены

**Правило 2. Факт должен быть подтверждён доказательством.**

Недопустимо утверждение факта без ссылки на доказательство. Если доказательство отсутствует — такой факт не может быть включён в правовую позицию.

**Правило 3. Доказательство должно быть легитимным.**

Проверить доказательство по четырём критериям (относимость, допустимость, достоверность, достаточность) в соответствии с 01-анализ-иска.md.

**Правило 4. Связь между элементами должна быть прямой.**

Норма должна непосредственно регулировать данный факт, доказательство — непосредственно подтверждать данный факт.

#### 2.3. Формат триады

```markdown
### Утверждение [N]. [Название утверждения]

**Норма закона:** [статья, часть, пункт] [наименование закона] — [краткая суть нормы]

**Факт:** [описание фактического обстоятельства]

**Доказательство:** [наименование документа, реквизиты, ссылка на приложение]

**Вывод:** [логическое следствие]
```

#### 2.4. Примеры триад

**Пример 1 (для ответчика по иску прокурора об изъятии прудов):**

```markdown
### Утверждение 1. Пруды являются частной собственностью ответчика

**Норма закона:** Часть 2 статьи 8 Водного кодекса РФ — «Пруд, расположенный в границах земельного участка, принадлежащего на праве собственности юридическому лицу, находится в собственности этого юридического лица».

**Факт:** Пруды расположены в границах земельного участка с кадастровым номером 50:08:0000000:15, который принадлежит ответчику на праве собственности.

**Доказательство:** Выписка из ЕГРН от 15.01.2024 № 1234 (приложение № 1); договор купли-продажи № 75 от 09.09.2004 (приложение № 2).

**Вывод:** Пруды являются частной собственностью ответчика. Статья 6 Водного кодекса РФ (водные объекты общего пользования) к ним не применима, поскольку она регулирует водные объекты в государственной собственности.
```

**Пример 2 (для истца по спору с УК коттеджного посёлка):**

```markdown
### Утверждение 1. Договор управления не предусматривает дополнительный сбор

**Норма закона:** Статья 162 Жилищного кодекса РФ — договор управления должен содержать перечень услуг и размер платы; изменение размера платы возможно только в порядке, установленном договором.

**Факт:** Пункт 5.2 договора управления от 01.01.2020 не предусматривает сбора «на развитие инфраструктуры» в размере 5 000 рублей, который УК начала взимать с января 2023 года.

**Доказательство:** Копия договора управления от 01.01.2020 (приложение № 1); квитанции об оплате за январь — март 2023 года с новым сбором (приложения № 2–4).

**Вывод:** УК не вправе требовать уплату дополнительного сбора, не предусмотренного договором.
```

**Пример 3 (для ответчика по спору с СНТ о взыскании взносов):**

```markdown
### Утверждение 1. Решение собрания об установлении взносов принято с нарушением процедуры

**Норма закона:** Часть 19 статьи 17 Федерального закона № 217-ФЗ — решение общего собрания членов товарищества, принятое при отсутствии кворума, является ничтожным независимо от обжалования.

**Факт:** На общем собрании СНТ «Берёзка» от 15.03.2023 присутствовало 30 членов из 120, что составляет 25% от общего числа членов.

**Доказательство:** Журнал регистрации участников собрания от 15.03.2023 (истребуется через суд); список членов СНТ (имеется у ответчика).

**Вывод:** Решение собрания об установлении взносов ничтожно, у ответчика нет обязанности их уплачивать.
```

### Шаг 3. Выстраивание иерархии триад

Расположить триады в следующем порядке.

#### 3.1. Порядок расположения

| Уровень                               | Тип триад                                                    | Назначение                                                |
| :------------------------------------ | :----------------------------------------------------------- | :-------------------------------------------------------- |
| **Уровень 1. Базовые триады**         | Устанавливают фундаментальные обстоятельства (право собственности, легитимность субъекта, существование правоотношения) | Создают основу, без которой остальные триады теряют смысл |
| **Уровень 2. Основные триады**        | Непосредственно опровергают доводы истца (или обосновывают требования истца) | Являются ядром правовой позиции                           |
| **Уровень 3. Вспомогательные триады** | Усиливают основные, блокируют альтернативные аргументы оппонента, опровергают возможные возражения | Повышают устойчивость позиции                             |

#### 3.2. Пример иерархии (для ответчика)

| Уровень | Утверждение                                                  | Роль                                                 |
| :------ | :----------------------------------------------------------- | :--------------------------------------------------- |
| 1       | Пруды являются частной собственностью ответчика              | Базовое (устанавливает право)                        |
| 1       | Приватизация 2004 года была законной                         | Базовое (подтверждает законность владения)           |
| 2       | Статья 85 ЗК РФ не подлежит применению                       | Основное (опровергает довод истца)                   |
| 2       | Гидравлическая связь не прекращает право собственности       | Основное (опровергает довод истца)                   |
| 3       | Ссылки истца на ст. 27 и ст. 102 ЗК РФ не создают оснований для изъятия | Вспомогательное (блокирует альтернативные аргументы) |

### Шаг 4. Проверка системных связей

Убедиться, что триады образуют логически непротиворечивую систему.

#### 4.1. Критерии проверки

| Критерий                          | Вопрос для проверки                                       | Несоответствие                                               |
| :-------------------------------- | :-------------------------------------------------------- | :----------------------------------------------------------- |
| **Непротиворечивость**            | Не противоречат ли триады друг другу?                     | Две триады утверждают взаимоисключающие факты                |
| **Полнота**                       | Все ли существенные обстоятельства охвачены триадами?     | Есть обстоятельства, которые не подтверждены ни одной триадой |
| **Логическая последовательность** | Выстроены ли триады в цепочку, ведущую к целевому выводу? | Целевой вывод не вытекает из триад (или вытекает неочевидным образом) |
| **Достаточность**                 | Совокупность триад достаточна для вывода?                 | Отсутствует триада по ключевому обстоятельству               |

#### 4.2. Визуализация системных связей

Для проверки связей может быть построена следующая схема:

```markdown
Триада 1 (Базовое) 
    ↓
Триада 2 (Базовое)
    ↓
Триада 3 (Основное)
    ↓
Триада 4 (Основное)
    ↓
Триада 5 (Вспомогательное)
    ↓
ЦЕЛЕВОЙ ВЫВОД
```

#### 4.3. Формат вывода

```markdown
**Проверка системных связей:**

- Непротиворечивость: ✅ / ❌ (если ❌ — указать противоречия)
- Полнота: ✅ / ❌ (если ❌ — указать, каких триад не хватает)
- Логическая последовательность: ✅ / ❌
- Достаточность: ✅ / ❌

**Общий вывод:** система триад [является / не является] достаточной для обоснования целевого вывода.
```

### Шаг 5. Оформление итоговой правовой позиции

Сформировать итоговый документ, который может быть использован как:

- Основа для отзыва на иск
- Основа для встречного иска
- Основа для апелляционной жалобы
- План устного выступления в суде

#### 5.1. Структура итогового документа

```markdown
## ПРАВОВАЯ ПОЗИЦИЯ [наименование стороны]

### Итоговый вывод
[одно предложение, неизбежно следующее из всех утверждений ниже]

---

### Обоснование

#### Утверждение 1. [Название]

**Норма закона:** [статья, часть, пункт] — [суть нормы]

**Факт:** [описание]

**Доказательство:** [ссылка на документ]

**Вывод:** [логическое следствие]

---

#### Утверждение 2. [Название]
[и т.д.]

---

### Сводная таблица

| № | Утверждение | Норма | Доказательство | Вывод |
| :--- | :--- | :--- | :--- | :--- |
| 1 | ... | ... | ... | ... |
| 2 | ... | ... | ... | ... |

---

### ИТОГОВЫЙ ВЫВОД
[повтор целевого вывода с кратким обоснованием из 2–3 предложений]

---

### Примечание по использованию

Настоящая правовая позиция может быть использована:
- как основа для [отзыва на иск / встречного иска / апелляционной жалобы]
- как план устного выступления в судебном заседании
- для подготовки письменных пояснений по делу
```

#### 5.2. Пример итогового документа (для ответчика)

```markdown
## ПРАВОВАЯ ПОЗИЦИЯ ООО «РЫБОКОМБИНАТ»

### Итоговый вывод
Иск прокурора об истребовании земельного участка и акватории прудов не подлежит удовлетворению, поскольку пруды являются частной собственностью ответчика, а нормы, на которые ссылается истец, не применимы к спорным правоотношениям.

---

### Обоснование

#### Утверждение 1. Пруды являются частной собственностью ответчика

**Норма закона:** Часть 2 статьи 8 Водного кодекса РФ — пруд, расположенный в границах земельного участка, принадлежащего на праве собственности юридическому лицу, находится в собственности этого юридического лица.

**Факт:** Пруды расположены в границах земельного участка с кадастровым номером 50:08:0000000:15, который принадлежит ответчику на праве собственности.

**Доказательство:** Выписка из ЕГРН от 15.01.2024 № 1234; договор купли-продажи № 75 от 09.09.2004.

**Вывод:** Пруды являются частной собственностью ответчика. Статья 6 Водного кодекса РФ (водные объекты общего пользования) не применима.

---

#### Утверждение 2. Статья 85 Земельного кодекса РФ не подлежит применению

**Норма закона:** Часть 12 статьи 85 Земельного кодекса РФ регулирует правовой режим земель населённых пунктов.

**Факт:** Земельный участок ответчика относится к категории «земли сельскохозяйственного назначения».

**Доказательство:** Выписка из ЕГРН (приложение № 1); договор купли-продажи № 75 от 09.09.2004 (п. 1.2).

**Вывод:** Статья 85 ЗК РФ не подлежит применению к спорным правоотношениям.

---

### Сводная таблица

| № | Утверждение | Норма | Доказательство | Вывод |
| :--- | :--- | :--- | :--- | :--- |
| 1 | Пруды — частная собственность | ч. 2 ст. 8 ВК РФ | Выписка ЕГРН, договор | Ст. 6 ВК РФ не применима |
| 2 | Ст. 85 ЗК РФ не применима | ч. 12 ст. 85 ЗК РФ | Выписка ЕГРН | Земли сельхозназначения |
| 3 | Гидравлическая связь не прекращает право собственности | п. 2 ст. 77 ЗК РФ | Техническая документация | Пруды на водотоках разрешены |
| 4 | Приватизация 2004 года законна | ст. 2 Закона № 137-ФЗ | Договор купли-продажи | Право собственности возникло законно |

### ИТОГОВЫЙ ВЫВОД

Ни одна из норм, на которые ссылается истец, не предусматривает изъятие земельного участка или акватории прудов при установленных по делу фактах. Следовательно, иск удовлетворению не подлежит.
```

## Контрольный чек-лист правовой позиции

Перед использованием правовой позиции проверить:

| №    | Проверка                                                     | Статус |
| :--- | :----------------------------------------------------------- | :----- |
| 1    | Целевой вывод сформулирован чётко и однозначно               | ☐      |
| 2    | Целевой вывод декомпозирован на 3–7 ключевых утверждений     | ☐      |
| 3    | Для каждого утверждения построена триада (Норма — Факт — Доказательство) | ☐      |
| 4    | Каждая норма действующая и применима к ситуации              | ☐      |
| 5    | Каждый факт подтверждён допустимым доказательством           | ☐      |
| 6    | Триады выстроены в логической последовательности (базовые → основные → вспомогательные) | ☐      |
| 7    | Триады не противоречат друг другу                            | ☐      |
| 8    | Совокупность триад достаточна для обоснования целевого вывода | ☐      |
| 9    | Правовая позиция оформлена в виде, готовом для использования в суде | ☐      |

## Типовые ошибки при формулировании правовой позиции

| Ошибка                                         | Последствие                                         | Как избежать                                                 |
| :--------------------------------------------- | :-------------------------------------------------- | :----------------------------------------------------------- |
| **Одно утверждение содержит несколько фактов** | Сложно доказать, оппонент может атаковать частями   | Декомпозировать на отдельные утверждения                     |
| **Факт не подтверждён доказательством**        | Суд не примет утверждение                           | До включения в позицию убедиться в наличии доказательства    |
| **Норма не относится к ситуации**              | Оппонент укажет на неприменимость, позиция ослабнет | Проверить норму по шагу 2 из 01-анализ-иска.md               |
| **Триады не связаны в систему**                | Позиция выглядит как набор разрозненных аргументов  | Построить логическую цепочку, проверить связи                |
| **Отсутствуют базовые триады**                 | Позиция не имеет фундамента                         | Начать с установления права собственности/легитимности       |
| **Слишком много триад (более 7)**              | Позиция перегружена, главное теряется               | Оставить только ключевые, второстепенные — во вспомогательные |

## Ограничения метода

Настоящий алгоритм не заменяет:

- Анализ фактической стороны дела, который может выявить триады, не очевидные при формальном построении
- Учёт процессуальной тактики (например, частичное признание иска может быть более выгодным, чем полное отрицание)
- Консультацию с квалифицированным юристом по сложным делам, где требуется нестандартная аргументация

Сформированная правовая позиция является основой для процессуальных документов, но не гарантирует процессуального успеха, который зависит от качества представления позиции в суде, процесса доказывания и иных факторов.
