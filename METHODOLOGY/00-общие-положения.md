# Общие положения (инвариантные принципы)

## 1. Структура правовой позиции
Норма закона → Факт → Вывод

## 2. Распределение бремени доказывания
Истец доказывает основания иска. Ответчик — возражения.

## 3. Приоритет специальной нормы
Lex specialis derogat legi generali.

## 4. Четыре элемента спора
Факты → Нормы → Доказательства → Процессуальные действия

## 5. Критерии оценки доказательств
Относимость, допустимость, достоверность, достаточность.

## 6. Иерархия нормативных актов
Конституция → ФКЗ → Кодексы → ФЗ → Подзаконные акты → Письма (необязательны)

## 7. Основные процессуальные сроки
Апелляция — 1 месяц. Исковая давность — 3 года. Исполнительный лист — 3 года.
