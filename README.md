# Экспертная система для работы с нормативными документами

Система для анализа, структурирования и выбора разделов нормативных документов с последующим экспортом.

## Возможности

- Сканирование папок с документами (`.md`, `.txt`)
- Автоматическое разделение документов на структурные единицы (главы, статьи, разделы)
- Выбор необходимых разделов через веб-интерфейс
- Экспорт выбранных разделов в JSON
- Создание рабочих сессий с сохранением промтов
- Поддержка YAML-метаданных для фильтрации документов

## Быстрый запуск

### 1. Установите Python

Скачайте Python 3.8 или новее с [python.org](https://python.org)

### 2. Откройте командную строку в папке проекта

```bash
cd D:\EXPERT
```

### 3. Создайте виртуальное окружение (однократно)

```bash
python -m venv venv
```

### 4. Активируйте окружение

```bash
venv\Scripts\activate
```

### 5. Установите зависимости

```bash
pip install streamlit chardet pyyaml
```

### 6. Запустите приложение

```bash
streamlit run app.py
```

### 7. Откройте в браузере

Перейдите по адресу: `http://localhost:8501`

## Правила разметки файлов по папкам

### 📁 NORMATIVE (Нормативные документы)

**Назначение:** законы, кодексы, постановления, приказы

**Особенности обработки:**
- Документы автоматически разбиваются на **главы** (по умолчанию)
- Поддерживается разбиение на **статьи** с фильтрацией через YAML

**Формат заголовков глав:**
```
Глава 1. Общие положения
ГЛАВА 2. Права и обязанности
Глава 6.1. Особенности регулирования
```

**YAML-метаданные для статей:**
```yaml
---
title: Земельный кодекс РФ
split_by: articles          # разделение по статьям
extract_ranges:             # диапазоны статей
  - 1-10
  - 15-20
extract_only:               # конкретные статьи
  - 11
  - 25
---
```

**Пример документа:**
```markdown
---
title: Федеральный закон "О землеустройстве"
split_by: articles
extract_ranges:
  - 1-5
---

# Глава 1. Общие положения

**Статья 1.** Основные понятия
Землеустройство - мероприятия по изучению состояния земель...

**Статья 2.** Правовая основа землеустройства
Правовую основу составляют Конституция РФ, настоящий закон...
```

### 📁 METHODOLOGY (Методические документы)

**Назначение:** методики, инструкции, рекомендации

**Особенности обработки:**
- Документы сохраняются **целиком** (не разбиваются)
- Подходит для методических указаний и инструкций

**Пример документа:**
```markdown
---
title: Методика определения кадастровой стоимости
---

# 1. Общие положения

Настоящая методика устанавливает порядок определения кадастровой стоимости...

# 2. Порядок расчета

Расчет кадастровой стоимости осуществляется по формуле...
```

### 📁 STRUCTURED (Структурированные документы)

**Назначение:** документы с четкой вложенной структурой

**Особенности обработки:**
- Разбиение по **заголовкам в квадратных скобках** `[Заголовок]`
- Идеально для технической документации и регламентов

**Формат заголовков:**
```
[Раздел 1. Общие положения]
Текст раздела...

[Раздел 2. Требования к документам]
Текст раздела...

[Подраздел 2.1. Состав документов]
Текст подраздела...
```

**Пример документа:**
```markdown
---
title: Регламент предоставления услуги
---

[1. Общие положения]
1.1. Настоящий регламент определяет порядок...
1.2. Услуга предоставляется на безвозмездной основе...

[2. Порядок подачи заявления]
2.1. Заявление подается в электронном виде...
2.2. Срок рассмотрения - 10 рабочих дней...

[3. Основания для отказа]
3.1. Отсутствие необходимых документов...
```

### 📁 EXPERTISE (Экспертные заключения)

**Назначение:** экспертные заключения, решения, акты

**Особенности обработки:**
- Документы сохраняются **целиком**
- Подходит для готовых экспертных мнений и прецедентов

**Пример документа:**
```markdown
---
title: Экспертное заключение №123 от 15.03.2024
---

# Заключение эксперта

## Вопрос 1: О правомерности отказа в предоставлении участка

**Ответ:** Отказ является неправомерным, так как...

## Выводы

На основании анализа нормативной базы...
```

## YAML-метаданные (общий формат)

```yaml
---
title: Полное наименование документа  # заголовок документа
split_by: articles                    # articles | chapters (только для NORMATIVE)
extract_ranges:                       # диапазоны (только с split_by: articles)
  - 1-10
  - 15-20
extract_only:                         # конкретные элементы
  - 11
  - 25
---
```

## Работа с программой

1. **Загрузка документов** — поместите файлы `.md` или `.txt` в соответствующие папки
2. **Сканирование** — нажмите "Сканировать папки" в боковой панели
3. **Выбор разделов** — отметьте нужные разделы в интерфейсе
4. **Создание сессии** — создайте рабочую сессию
5. **Экспорт** — экспортируйте выбранные разделы в сессию

## Быстрый запуск через start.bat

Создайте файл `start.bat` в папке проекта:

```batch
@echo off
cd /d D:\EXPERT
call venv\Scripts\activate.bat
streamlit run app.py
pause
```

Теперь достаточно дважды кликнуть на `start.bat`.

## Устранение проблем

### Ошибка "Python не найден"

Установите Python с [python.org](https://python.org) и добавьте его в PATH при установке.

### Ошибка при активации venv

Выполните в PowerShell:
```bash
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### База данных не сохраняется

Убедитесь, что папка `data` существует и в неё есть права на запись.
