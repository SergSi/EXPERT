#  База знаний - экспертная система

## 🎯 Основные возможности

### 📋 Управление базой знаний
- **Автоматическое сканирование** документов из 4-х типов папок:
  - 📖 Нормативные акты (разделение по "ГЛАВА")
  - 📚 Методические материалы (разделение по заголовкам markdown)
  - 🗂️ Структурированные документы (разделение по квадратным скобкам)
  - 👨‍⚖️ Экспертные заключения (сохраняются целиком)
- **Интеллектуальная обработка** текстов с очисткой от служебной информации
- **Автоматическое определение кодировки** файлов
- **Гибкая конфигурация путей** через JSON файл

### 🎯 Выбор материалов для анализа
- **Фильтрация** по типу документа, папке и поиску
- **Массовый выбор** разделов
- **Компактный интерфейс** с адаптацией для мобильных устройств
- **Сохранение выбора** между сессиями

### 🤖 Генерация промтов для ИИ
- **Несколько шаблонов** ответов:
  - 📊 Аналитический отчет (детальный анализ с рекомендациями)
  - ⚡ Краткий ответ с рекомендациями
  - 📝 Стандартный развернутый ответ
- **Автоматическое создание** файлов сессии:
  - `all_sections.md` - все выбранные разделы
  - `deepseek_prompt.txt` - готовый промт для ИИ
  - `report.txt` - отчет по сессии
  - `sections_data.json` - данные в формате JSON
  - `template_info.json` - информация о шаблоне

### ⚙️ Администрирование
- **Гибкая настройка путей** через `config.json`
- **Импорт/экспорт** базы данных
- **Управление шаблонами** (создание, редактирование, перезагрузка)
- **Полная статистика** по документам и разделам

## 🚀 Установка и запуск

### Требования
- Python 3.8 или выше
- Доступ к интернету для установки зависимостей

### Установка зависимостей

```bash
# Установка необходимых библиотек
pip install streamlit pandas pyyaml chardet striprtf

# Или установка из файла requirements.txt
pip install -r requirements.txt
```

### Запуск приложения

```bash
# Основной способ запуска
streamlit run app.py

# С дополнительными параметрами (опционально)
streamlit run app.py --server.port 8501 --server.address 0.0.0.0
```

После запуска откроется браузер с веб-интерфейсом приложения по адресу: `http://localhost:8501`

## ⚙️ КОНФИГУРАЦИЯ

### Файл конфигурации `config.json`

Приложение использует JSON файл `config.json` для настройки путей к папкам с документами. Файл должен находиться в той же директории, что и `app.py`.

#### Пример файла `config.json`:
```json
{
  "folders": {
    "normative": "D:\\YandexDisk\\WORK\\EXPERT\\BD\\NORMATIVE",
    "methodology": "D:\\YandexDisk\\WORK\\EXPERT\\BD\\METHODOLOGY",
    "structured": "D:\\YandexDisk\\WORK\\EXPERT\\BD\\STRUCTURED",
    "expertise": "D:\\YandexDisk\\WORK\\EXPERT\\BD\\EXPERTISE"
  },
  "database_path": "./knowledge_database.db",
  "templates_path": "./templates.json",
  "expert_sessions_path": "./expert_sessions"
}
```

#### Параметры конфигурации:
- **`folders`** - пути к папкам с документами разных типов:
  - `normative` - нормативные акты
  - `methodology` - методические материалы
  - `structured` - структурированные документы
  - `expertise` - экспертные заключения
- **`database_path`** - путь к папке с базой данных
- **`templates_path`** - путь к файлу с шаблонами
- **`expert_sessions_path`** - путь к папке для сохранения сессий

#### Порядок работы с конфигурацией:

1. **Первый запуск**: Если файл `config.json` не существует, приложение создаст его с путями по умолчанию в текущей директории.

2. **Настройка путей**: Отредактируйте файл `config.json` в любом текстовом редакторе, указав актуальные пути к вашим папкам с документами.

3. **Проверка доступности**: Во вкладке "Настройки" можно проверить доступность всех папок.

4. **Скачивание/загрузка**: Текущую конфигурацию можно скачать во вкладке "Настройки" для редактирования или сохранения резервной копии.

## 📋 Порядок работы

### Шаг 0: Настройка конфигурации (ПЕРВЫЙ РАЗ)
1. **Запустите приложение** первый раз: `streamlit run app.py`
2. **Перейдите во вкладку "Настройки"**
3. **Нажмите "Создать config.json"** - будет создан файл конфигурации с путями по умолчанию
4. **Отредактируйте `config.json`** - укажите актуальные пути к вашим папкам с документами
5. **Перезапустите приложение** для применения новой конфигурации

### Шаг 1: Подготовка документов
1. **Разместите документы** в папках, указанных в `config.json`:
   - Нормативные акты → в папку для `normative`
   - Методические материалы → в папку для `methodology`
   - Структурированные документы → в папку для `structured`
   - Экспертные заключения → в папку для `expertise`

2. **Форматы документов**:
   - `.md` - Markdown файлы (рекомендуется)
   - `.txt` - Текстовые файлы
   - `.rtf` - Файлы RTF

### Шаг 2: Инициализация базы
1. **Перейдите на вкладку "Администрирование"**
2. **Нажмите "Сканировать папки"**
3. **Дождитесь завершения** сканирования (статус в уведомлениях)

### Шаг 3: Выбор материалов
1. **Перейдите на вкладку "Выбор разделов"**
2. **Используйте фильтры** для поиска нужных материалов
3. **Выберите разделы** с помощью чекбоксов
4. **Сохраните выбор** кнопкой "💾 Сохранить выбор"

### Шаг 4: Настройка шаблона
1. **Перейдите на вкладку "Выбор шаблона"**
2. **Выберите подходящий шаблон** ответа

### Шаг 5: Создание файлов для ИИ
1. **Нажмите "🤖 Создать файлы"**
2. **Скачайте готовые файлы** во вкладке "Выбор шаблона"

### Шаг 6: Работа с ИИ
1. **Откройте файл** `deepseek_prompt.txt`
2. **Скопируйте содержимое** в чат с ИИ
3. **Получите структурированный ответ** на основе выбранных материалов

## 💡 Советы по работе

### Для настройки путей:
1. **Используйте абсолютные пути** в `config.json`
2. **Для Windows**: используйте двойные обратные слэши `\\` или обычные слэши `/`
3. **Проверяйте доступность** папок через интерфейс перед сканированием
4. **Создавайте резервные копии** `config.json` отдельно от проекта

### Для работы с документами:
1. **Группируйте документы** по темам в соответствующих папках
2. **Используйте фильтры** для быстрого поиска нужных материалов
3. **Сохраняйте выбор** перед созданием файлов
4. **Экспериментируйте с шаблонами** для разных типов задач

### Для работы в команде:
1. **Не коммитьте `config.json`** в репозиторий
2. **Создайте `config.example.json`** с примером структуры
3. **Используйте разные конфигурации** для работы

## ⚠️ Устранение неполадок

### Если приложение не запускается:
```bash
# Проверьте установку зависимостей
pip list | grep -E "streamlit|pandas|yaml|chardet|striprtf"

# Переустановите зависимости
pip install --force-reinstall streamlit pandas pyyaml chardet
```

### Если не находятся документы:
1. **Проверьте `config.json`** - правильность путей
2. **Проверьте доступность** папок во вкладке "Настройки"
3. **Убедитесь**, что файлы имеют расширения `.md` или `.txt`

### Если не работает конфигурация:
1. **Удалите `config.json`** и создайте новый через интерфейс
2. **Проверьте синтаксис JSON** - можно использовать онлайн валидатор
3. **Перезапустите приложение** после изменения конфигурации

## 📋 Поддерживаемые форматы документов

Приложение поддерживает три формата документов:

### 1. 📝 Markdown (`.md`)
- **Рекомендуемый формат**
- Поддерживает структурирование заголовками (`#`, `##`, `###`)


### 2. 📄 Текстовые файлы (`.txt`)

- Простой текстовый формат
- Автоматическое определение кодировки (UTF-8, Windows-1251, KOI8-R и др.)
- Поддерживает разделение по правилам для каждой папки
- Текстовый файл и файл Markdown (.md) Может содержать YAML метаданные в начале файла, которые используются для определения принадлежности раздела к конкретному нормативному документу:
  ```yaml
  ---
  title: Название документа
  date: 2024-01-01
  ---

### 3. 📋 RTF файлы (`.rtf`) 

- Формат Rich Text Format (Microsoft Word и др.)
