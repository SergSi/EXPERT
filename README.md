

# База знаний - экспертная система

## 🎯 Основные возможности

### 📋 Управление базой знаний
- **Автоматическое сканирование** документов из 4-х типов папок:
  - 📖 Нормативные акты (разделение по "ГЛАВА" или "СТАТЬЯ")
  - 📚 Методические материалы (сохраняются целиком)
  - 🗂️ Структурированные документы (разделение по квадратным скобкам `[Заголовок]`)
  - 👨‍⚖️ Экспертные заключения (сохраняются целиком)
- **Умное разделение нормативных документов** по главам (ГЛАВА I, ГЛАВА II)
- **Обработка текстов с очисткой от служебной информации** (КонсультантПлюс, ГАРАНТ)
- **Автоматическое определение кодировки** файлов
- **Гибкая конфигурация путей** через JSON файл
- **YAML метаданные** в начале файлов

### 🎯 Выбор материалов для анализа
- **Поиск и фильтрация** по документам и разделам
- **Пакетный выбор** (выбрать все/снять все)
- **Сохранение выбора** между сессиями
- **Интерактивный интерфейс** с подсветкой выбранных разделов

### 📁 Управление рабочими сессиями
- **Автоматическое создание сессий** с уникальными именами
- **Шаблоны промтов** - готовые структуры вопросов для разных типов задач
- **Экспорт выбранных материалов** в упрощенный JSON формат
- **Сохранение ответов** от AI

### 🤖 Подготовка к анализу ИИ
- **Система шаблонов промтов** с выбором активного шаблона
- **Автоматическое создание файла промта** из выбранного шаблона
- **Экспорт выбранных разделов** в `materials.json` для использования в промтах

### ⚙️ Администрирование
- **Гибкая настройка** через `config.json`
- **Проверка целостности** базы данных
- **Детальная статистика** по документам и разделам
- **Управление выбором** (очистка всех выборов)

## 🚀 Установка и запуск

### Требования
- Python 3.8 или выше
- Доступ к интернету для установки зависимостей

### Установка зависимостей

```bash
# Установка необходимых библиотек
pip install streamlit pyyaml chardet

# Или установка из файла requirements.txt
pip install -r requirements.txt
```

### Запуск приложения

```bash
# Основной способ запуска
streamlit run app.py

# С дополнительными параметрами (опционально)
streamlit run app.py --server.port 8501 --server.address 0.0.0.0
```

После запуска откроется браузер с веб-интерфейсом приложения по адресу: `http://localhost:8501`

## ⚙️ КОНФИГУРАЦИЯ

### Файл конфигурации `config.json`

Приложение использует JSON файл `config.json` для настройки путей к папкам с документами. Файл должен находиться в той же директории, что и `app.py`.

#### Пример файла `config.json`:
```json
{
  "folders": {
    "normative": "./NORMATIVE",
    "methodology": "./METHODOLOGY",
    "structured": "./STRUCTURED",
    "expertise": "./EXPERTISE"
  },
  "database_path": "./knowledge_database.db",
  "sessions_path": "./sessions",
  "templates_path": "./templates.json",
  "supported_extensions": [".md", ".txt"],
  "admin_enabled": true,
  "max_upload_size_mb": 100
}
```

#### Параметры конфигурации:
- **`folders`** - пути к папкам с документами разных типов:
  - `normative` - нормативные акты
  - `methodology` - методические материалы
  - `structured` - структурированные документы
  - `expertise` - экспертные заключения
- **`database_path`** - путь к папке с базой данных
- **`sessions_path`** - путь к папке для сохранения рабочих сессий
- **`templates_path`** - путь к файлу с шаблонами промтов
- **`supported_extensions`** - поддерживаемые расширения файлов
- **`admin_enabled`** - включение/выключение администрирования
- **`max_upload_size_mb`** - максимальный размер загружаемых файлов

#### Порядок работы с конфигурацией:

1. **Первый запуск**: Если файл `config.json` не существует, приложение создаст его с путями по умолчанию в текущей директории.

2. **Настройка путей**: Отредактируйте файл `config.json` в любом текстовом редакторе, указав актуальные пути к вашим папкам с документами.

3. **Проверка доступности**: Во вкладке "Настройки" можно проверить доступность всех папок.

4. **Скачивание/загрузка**: Текущую конфигурацию можно скачать во вкладке "Настройки" для редактирования или сохранения резервной копии.

## 🚀 Этапы полного цикла экспертизы

### **📋 Этап 1: Импорт документов**
1. **Получение исходных материалов** от заказчика
2. **Сортировка документов** по типам:
   - Нормативные акты → папка `NORMATIVE`
   - Методические материалы → папка `METHODOLOGY`
   - Структурированные данные → папка `STRUCTURED`
   - Предыдущие экспертизы → папка `EXPERTISE`
3. **Проверка форматов файлов** (поддержка: .md, .txt)
4. **Внесение YAML-метаданных** в начало документов (опционально):
   ```yaml
   ---
   title: "Градостроительный кодекс РФ"
   split_by: articles
   extract_only:
     - "5-7"          # Статьи 5, 6, 7 будут в ОДНОМ разделе
     - "10"           # Статья 10 будет отдельным разделом
     - "15-18"        # Статьи 15, 16, 17, 18 будут в ОДНОМ разделе
   ---
   ```

### **🔍 Этап 2: Индексирование**
1. **Запуск сканирования папок** через веб-интерфейс (вкладка "Настройки" или боковая панель)
2. **Автоматическое разбиение документов** на разделы:
   - Нормативные акты → по главам
   - Методические материалы → целиком
   - Структурированные документы → по квадратным скобкам `[Заголовок]`
   - Экспертные заключения → целиком
3. **Очистка текста** от служебных комментариев КонсультантПлюс и ГАРАНТ
4. **Извлечение метаданных** из YAML-заголовков
5. **Обновление статистики базы** (количество документов, разделов, слов)

### **🎯 Этап 3: Селекция материалов**
1. **Переход во вкладку "Выбор разделов"** в веб-интерфейсе
2. **Применение фильтров** для поиска релевантных материалов:
   - Поиск по тексту в названиях документов и разделов
   - Фильтр по конкретным документам
3. **Выбор разделов** путем установки флажков в чекбоксах
4. **Сохранение выбора** в базу данных

### **🎯 Этап 4: Выбор шаблона промта**
1. **Переход во вкладку "Настройки"** → раздел "Выбор шаблона вопроса"
2. **Просмотр доступных шаблонов** и их описаний
3. **Выбор подходящего шаблона** для конкретной задачи
4. **Сохранение выбора шаблона** для будущих сессий

### **📁 Этап 5: Создание рабочей сессии**
1. **Переход во вкладку "Рабочие сессии"**
2. **Создание новой сессии**:
   - Автоматическое имя (session_YYYYMMDD_HHMMSS)
   - Или указание собственного имени
   - Автоматическое создание файла `prompt.txt` из выбранного шаблона
3. **Выбор активной сессии** для работы
4. **Экспорт выбранных материалов** в сессию

### **🤖 Этап 6: Настройка промта и подготовка к анализу**
1. **Работа с промтом**:
   - Использование готового `prompt.txt` из шаблона
   - Ручное редактирование при необходимости
2. **Проверка структуры сессии**:
   - Промт-файл `prompt.txt`
   - Файл `materials.json` с выбранными разделами

### **🧠 Этап 7: Анализ ИИ**
1. **Открытие файлов сессии**
2. **Использование промта** одним из способов:
   - Копирование содержимого `prompt.txt`
   - Загрузка `materials.json` с выбранными разделами
3. **Получение ответа** от ИИ-ассистента (DeepSeek или другой)
4. **Анализ ответа** на соответствие требованиям

### **📄 Этап 8: Документирование и сохранение**
1. **Сохранение ответа AI** в отдельный файл
2. **Форматирование ответа** в соответствии с корпоративными стандартами
3. **Архивация сессии** для дальнейшего использования

### **✅ Завершение цикла**
1. **Сохранение всех файлов сессии** в архиве
2. **Контроль качества** — финальная проверка
3. **Передача результата** заказчику
4. **Очистка выборов** в базе для следующей задачи

## 🎯 Шаблоны промтов

Система поддерживает шаблоны промтов для различных типов задач. По умолчанию доступен шаблон "📝 Стандартный ответ". Шаблоны хранятся в файле `templates.json` и могут быть расширены пользователем.

### Структура шаблона:
```json
{
  "id": "standard",
  "name": "📝 Стандартный ответ",
  "description": "Развернутый профессиональный ответ с анализом",
  "prompt": "Ты — эксперт в области землепользования и кадастра.\n\nНа основе предоставленных материалов подготовь развернутый профессиональный ответ.",
  "selected": true
}
```

## 🆘 Устранение неполадок

### Проблема: Файлы не отображаются в базе
**Решение:**
1. Проверьте наличие файлов в соответствующих папках
2. Убедитесь, что файлы имеют расширения .md или .txt
3. Нажмите кнопку "Сканировать папки" во вкладке "Настройки"

### Проблема: Сессии не создаются
**Решение:**
1. Проверьте права доступа к папке `sessions`
2. Убедитесь, что выбран шаблон промта
3. Проверьте конфигурацию в файле `config.json`

### Проблема: Не сохраняется выбор разделов
**Решение:**
1. Нажмите кнопку "💾 Сохранить выбор" после выбора разделов
2. Проверьте права доступа к папке базы данных
3. Убедитесь, что есть несохраненные изменения (отображается предупреждение)
