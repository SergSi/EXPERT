## УРОК 1: 📥 Установка Python

### Для Windows (самый простой способ):

1. **Скачайте установщик:**
   - Перейдите на [официальный сайт Python](https://www.python.org/downloads/)
   - Нажмите большую желтую кнопку "Download Python"
   - Выберите версию **3.8 или выше**

2. **Установите Python:**
   - Запустите скачанный файл (например, `python-3.11.5.exe`)
   - **ВАЖНО:** Поставьте галочку "Add Python to PATH" ✓
   - Нажмите "Install Now"
   - Дождитесь окончания установки

3. **Проверьте установку:**
   - Нажмите `Win + R`
   - Введите `cmd` и нажмите Enter
   - В черном окне введите: `python --version`
   - Вы должны увидеть версию Python (например, `Python 3.11.5`)

### Для macOS:
```bash
# Способ 1: Через официальный сайт (как для Windows)
# Способ 2: Через Homebrew (если установлен):
brew install python
```

### Для Linux:
```bash
# Ubuntu/Debian:
sudo apt update
sudo apt install python3 python3-pip

# Fedora:
sudo dnf install python3 python3-pip
```

## УРОК 2: 🛠️ Установка программы и зависимостей

### Шаг 1: Скачайте программу
1. Создайте папку для проекта (например, `C:\ExpertSystem` или `~/ExpertSystem`)
2. Поместите в нее файлы:
   - `app.py` (основная программа)
   - `README.md` (инструкция)
   - (опционально) `requirements.txt` (список зависимостей)

### Шаг 2: Откройте командную строку в папке с программой

**Для Windows:**
1. Откройте папку с программой в Проводнике
2. Нажмите на адресную строку (где путь к папке)
3. Введите `cmd` и нажмите Enter
4. Откроется командная строка в нужной папке

**Для macOS/Linux:**
```bash
cd ~/ExpertSystem  # перейдите в папку с программой
pwd  # проверьте, что вы в правильной папке
```

### Шаг 3: Установите зависимости

**Вариант А (если есть requirements.txt):**
```bash
pip install -r requirements.txt
```

**Вариант Б (если файла нет):**
```bash
pip install streamlit pandas pyyaml chardet
```

**Если pip не работает:**
```bash
# Для Windows:
python -m pip install streamlit pandas pyyaml chardet

# Для macOS/Linux:
pip3 install streamlit pandas pyyaml chardet
```

## УРОК 4: ⚙️ Работа с JSON конфигурацией

### Что такое JSON?
- Простой текстовый формат для настроек
- Похож на структуру данных в Python
- Использует фигурные скобки `{}` и квадратные скобки `[]`

### Как отредактировать config.json:

**Шаг 1: Создайте/найдите файл**
После первого запуска появится файл `config.json` в папке с программой.

**Шаг 2: Откройте в редакторе**
- Используйте **Блокнот** (Windows)
- Или **Notepad++** (рекомендуется)
- Или **VS Code** (профессиональный вариант)

**Шаг 3: Понять структуру:**
```json
{
  "folders": {
    "normative": "C:/Documents/NORMATIVE",
    "methodology": "C:/Documents/METHODOLOGY",
    "structured": "C:/Documents/STRUCTURED",
    "expertise": "C:/Documents/EXPERTISE"
  }
}
```

**Шаг 4: Измените пути:**
1. Укажите **правильные пути** к вашим папкам
2. Используйте `/` вместо `\` для разделителей
3. Сохраните файл

**Шаг 5: Перезапустите программу**
Изменения вступят в силу после перезапуска.

## УРОК 5: 📝 Создание YAML заголовков в документах

### Что такое YAML заголовок?
- Служебная информация в начале документа
- Позволяет задавать метаданные
- Помогает системе правильно определить документ

### Как добавить YAML заголовок:

**Формат:**
```yaml
---
title: Градостроительный кодекс Российской Федерации
author: Государственная Дума
date: 2004-12-29
type: федеральный закон
number: 190-ФЗ
---

Далее идет обычный текст документа...
```

### Пошаговая инструкция:

1. **Откройте текстовый редактор** (Блокнот, Notepad++ и т.д.)

2. **В начале файла добавьте:**
   ```
   ---
   title: Название вашего документа
   ---
   ```

3. **Сохраните файл** с расширением `.md` или `.txt`

4. **Дополнительные поля** (опционально):
   ```yaml
   ---
   title: Название документа
   author: Автор
   date: 2024-01-15
   status: действующий
   version: 2.0
   ---
   ```

### Важные правила:
- Начинается с `---` на отдельной строке
- Заканчивается `---` на отдельной строке
- Поля в формате `ключ: значение`
- Между заголовком и основным текстом — пустая строка

## УРОК 6: 🗂️ Разметка структурированных документов

### Типы документов и их разметка:

#### 1. 📖 **Нормативные акты** (папка NORMATIVE)
**Разделяются по главам:**
```
ГЛАВА I. ОБЩИЕ ПОЛОЖЕНИЯ
Текст первой главы...

ГЛАВА II. ПРАВА И ОБЯЗАННОСТИ
Текст второй главы...
```

**Правила:**
- Используйте `ГЛАВА` или `Глава`
- Добавьте номер (римский или арабский)
- После номера — точка, тире или двоеточие

#### 2. 📚 **Методические материалы** (папка METHODOLOGY)
**Используйте заголовки Markdown:**
```
# Основной заголовок уровня 1

Текст раздела...

## Подраздел уровня 2

Текст подраздела...
```

**Правила:**
- `#` — заголовок 1 уровня
- `##` — заголовок 2 уровня
- После решетки обязательно пробел

#### 3. 🗂️ **Структурированные документы** (папка STRUCTURED)
**Используйте квадратные скобки:**
```
[Общие положения]
Текст раздела об общих положениях.

[Требования к документации]
Текст требований к документации.
```

**Правила:**
- Каждый раздел в отдельных квадратных скобках
- Скобки на отдельной строке
- Без лишних символов внутри скобок

#### 4. 👨‍⚖️ **Экспертные заключения** (папка EXPERTISE)
**Не требуют разметки** — сохраняются целиком.

## 📚 Шпаргалка по командам

### Основные команды:
```bash
# Проверить версию Python
python --version

# Установить библиотеку
pip install название_библиотеки

# Запустить программу
streamlit run app.py

# Остановить программу
Ctrl + C
```

### Частые проблемы и решения:

1. **"python не является внутренней или внешней командой"**
   → Переустановите Python с галочкой "Add to PATH"

2. **"ModuleNotFoundError"**
   → Установите недостающую библиотеку: `pip install имя_модуля`

3. **Не открывается браузер**
   → Перейдите вручную на `http://localhost:8501`

4. **Не находятся документы**
   → Проверьте пути в `config.json`
   → Проверьте расширения файлов (.md или .txt)
